SlotSure — Capacity-Aware Appointment and Reservation API

Stack: NestJS, TypeScript, PostgreSQL (with raw SQL for lock semantics), Prisma, Redis, BullMQ, k6

  • Designed an atomic reservation algorithm — validate input, lock the slot-capacity row, verify remaining capacity, create a held reservation with expiry, decrement capacity — committed in a single transaction to prevent double-booking.
  • Guaranteed exactly-once capacity release: expiry workers are idempotent, so a repeated job cannot restore a seat twice, and idempotency keys stop client retries from creating a second reservation.
  • Enforced a reservation state machine (held to confirmed, expired, or cancelled) rejecting invalid transitions, and proved it with concurrency tests where two simultaneous requests race for the final slot and exactly one succeeds.

DealerSync — Asynchronous Order-Import and Exception-Management API

Stack: NestJS, TypeScript, PostgreSQL, Redis, BullMQ, streaming CSV parser, Docker Compose

  • Built an asynchronous CSV order-import pipeline in which the upload request returns immediately and a dedicated worker parses rows in bounded batches, keeping request latency independent of file size.
  • Implemented independent per-row validation with partial success, so invalid rows are recorded with actionable reasons and downloadable error reports without discarding valid orders.
  • Made workers idempotent using deterministic keys and unique database constraints, so retries with exponential backoff cannot create duplicate orders; import progress and status persist across worker restarts.
